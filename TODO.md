- Familiar patterns and conventions

- Common interaction patterns
- No surprises in core functionality

**Intuitive:**
- Self-explanatory interface
- Clear call-to-actions
- Logical information architecture
- Easy to learn
- Minimal cognitive load
- Obvious next steps

#### Key Design Principles to Follow

1. **Typography:**
   - System fonts or Google Fonts
   - Maximum 2-3 font families
   - Clear hierarchy (h1-h6)
   - Readable font sizes (16px minimum for body)
   - Appropriate line heights (1.5-1.75 for body)

2. **Color:**
   - Primary color + 1-2 accent colors
   - Neutral grays for text
   - Semantic colors (success, error, warning, info)
   - Sufficient contrast ratios (WCAG AA minimum)
   - Consistent color usage

3. **Spacing:**
   - 8px base unit (or 4px for fine-tuning)
   - Consistent padding/margins
   - Generous white space
   - Logical spacing scale (8, 16, 24, 32, 48, 64...)

4. **Components:**
   - Reusable button styles
   - Consistent form elements
   - Standard card designs
   - Unified navigation patterns
   - Predictable modals/dialogs

5. **Layout:**
   - Grid-based layouts
   - Responsive breakpoints
   - Mobile-first approach
   - Clear content hierarchy
   - Logical flow (F-pattern or Z-pattern)

6. **Interaction:**
   - Smooth transitions (200-300ms)
   - Hover states on interactive elements
   - Focus indicators for accessibility
   - Loading states
   - Error states with helpful messages
   - Success confirmations
