# Version 2.5.10 - Correct Firebase auth provider constructors and methods

**Release Date:** 2026-01-30
**Type:** Patch Release
**Previous Version:** 2.5.9

## 🎯 Overview

Correct Firebase auth provider constructors and methods

## 🐛 Bug Fixes

- Correct Firebase auth provider constructors and methods

## 🔧 Improvements

- Changed auth.GoogleAuthProvider() to firebase.auth.GoogleAuthProvider()
- Changed auth.FacebookAuthProvider() to firebase.auth.FacebookAuthProvider()
- Changed auth.OAuthProvider() to firebase.auth.OAuthProvider()
- Changed auth.getAdditionalUserInfo() to firebase.auth.getAdditionalUserInfo()
- Changed auth.FieldValue to firebase.firestore.FieldValue

## 📝 Commit Message

```
fix: Correct Firebase auth provider constructors and methods

Fixed the issue where GoogleAuthProvider, FacebookAuthProvider, OAuthProvider, and getAdditionalUserInfo were being accessed incorrectly from the auth instance instead of the firebase.auth module. Also fixed FieldValue references to use firebase.firestore.FieldValue.

This resolves the error: "undefined is not a constructor (evaluating 'new auth.GoogleAuthProvider()')"

Changes:
- Changed auth.GoogleAuthProvider() to firebase.auth.GoogleAuthProvider()
- Changed auth.FacebookAuthProvider() to firebase.auth.FacebookAuthProvider()
- Changed auth.OAuthProvider() to firebase.auth.OAuthProvider()
- Changed auth.getAdditionalUserInfo() to firebase.auth.getAdditionalUserInfo()
- Changed auth.FieldValue to firebase.firestore.FieldValue
```
