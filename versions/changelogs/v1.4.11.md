# Version 1.4.11

**Date:** 2026-01-25
**Type:** Minor Release - Carousel UI Implementation

## Summary

Major UI overhaul introducing horizontal carousel navigation for educational content sections.

## New Features

### Carousel Implementation
- 🎠 Implemented horizontal carousel for Common Misconceptions (5 slides)
- 🎪 Implemented horizontal carousel for Comparison Strategies (5 slides)
- 👆 Touch/swipe support for mobile devices
- ⌨️ Keyboard navigation with arrow keys
- 🔘 Navigation buttons (prev/next) with disabled states
- ⚪ Dot indicators showing current position
- 🔢 Slide counter (e.g., "1 / 5")
- ✨ Smooth transitions with CSS transforms
- 📏 Auto-height adjustment per slide

## Technical Details

### Touch/Swipe Support
- Touch events: `touchstart`, `touchmove`, `touchend`
- Swipe threshold detection for natural feel
- Velocity-based swipe recognition

### Keyboard Navigation
- Left/Right arrow keys navigate between slides
- Focus management for accessibility
- Keyboard events only active when carousel is in viewport

### Transition Effects
- CSS `transform: translateX()` for smooth sliding
- Hardware-accelerated transitions
- Automatic height adjustment based on content

### Navigation Controls
- Previous/Next buttons with disabled states
- Dot indicators for visual position tracking
- Slide counter showing current position
- Auto-disable buttons at start/end of carousel
