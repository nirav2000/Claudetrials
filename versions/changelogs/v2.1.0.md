# Version 2.1.0 - Enhanced Educational Content & UX Improvements

**Release Date:** January 27, 2026
**Type:** Minor Release
**Previous Version:** 2.0.0

## 🎯 Overview

This release focuses on improving the educational experience and user interface with better content organization, enhanced version management, and refined default settings based on user feedback.

## ✨ New Features

### Educational Content Enhancements
- **"Why Fractions Matter" Section**: Added engaging real-world examples showing practical applications
  - 🍰 Sharing and fairness
  - 👨‍🍳 Cooking and baking measurements
  - 💰 Money and shopping (sales, discounts)
  - ⏱️ Time management
  - ⚽ Sports and statistics
- Better focus on practical learning for students

### Version Management Improvements
- **Interactive Changelog Modal**: Version selector now displays changelog in modal instead of navigation
  - Users can view version history without leaving current page
  - Better UX and smoother workflow
- **Individual Changelog Files**: Created dedicated markdown files for each version
  - v1.0.0, v1.4.10, v1.4.11, v1.4.12, v1.4.13
  - Enables rich, formatted version-specific information display

### Content Organization
- **Separate Project Files Section**: Moved technical documentation to dedicated collapsible section
  - Cleaner separation between educational and technical content
  - Improved navigation and reduced cognitive load
  - Better experience for primary users (students and teachers)

## 🔧 Improvements

### Default Settings Optimization
- **Hint Timeout Default**: Changed from 30 seconds to "Off"
  - Better default UX - hints don't auto-show
  - Encourages students to think independently first
  - Users can still enable timeout manually (30s, 45s, 60s, 90s options available)

### UI/UX Refinements
- Streamlined Learning Guide layout
- Removed verbose version history from main educational section
- Improved visual hierarchy and content flow
- Enhanced mobile responsiveness for new sections

## 🐛 Bug Fixes

- Fixed multiple UI and functionality issues from v2.0.0
- Resolved null value handling in keyboard input
- Improved carousel navigation reliability

## 📁 Technical Details

### Modified Files
- `js/core/config.js` - Updated version and default hint timeout
- `index.html` - Reorganized educational content sections
- `js/version/versionUI.js` - Changed version selector behavior
- `versions/changelogs/` - Added individual version changelogs
- `versions/version-manifest.json` - Updated with v2.1.0 entry

### Configuration Changes
```javascript
VERSION: '2.1.0'
DEFAULT_HINT_TIMEOUT: 0  // Changed from 30
```

## 🎓 Educational Impact

This release prioritizes the learning experience by:
1. Making educational content more relatable with real-world examples
2. Reducing distractions by organizing technical content separately
3. Encouraging independent thinking with hints disabled by default
4. Improving overall navigation and content discovery
