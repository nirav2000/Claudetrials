## 📝 Commit Message

```
fix: Switch authentication from redirect to popup mode for iPad compatibility

The debug panel revealed that Firebase redirect authentication is not
working on iPad - getRedirectResult() returns null after successful
Google sign-in. This is a known issue with Safari/iPad due to cookie
restrictions and session storage limitations.

Switched authMode from 'redirect' to 'popup' which:
- Works better on mobile devices
- Doesn't require maintaining state across page redirects
- Avoids Safari cookie/storage restrictions
- User mentioned a prior version worked well (likely used popup mode)

This should fix the issue where users sign in successfully but the
app doesn't recognize them when they return.
```
