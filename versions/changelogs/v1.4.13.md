# Version 1.4.13

**Date:** 2026-01-26
**Type:** Patch Release - Accessibility & Responsiveness

## Summary

Significant improvements to accessibility, responsive design, and user experience with focus on keyboard navigation, screen readers, and mobile devices.

## Changes

### Accessibility Improvements
- ♿ Fixed carousel arrows to properly center using `top: 50%` + `translateY(-50%)`
- 🎨 Added transform composition on hover: `translateY(-50%) scale(1.1)`
- 🔊 Added `aria-label` attributes to icon buttons for screen readers
- 🙈 Added `aria-hidden="true"` to decorative Material Icons
- ⌨️ Added visible `:focus` outline (2px solid, 2px offset) for keyboard navigation

### Mobile Enhancements
- 📱 Enhanced mobile problem grid: `grid-template-columns: 1fr`, `gap: 8px`
- 📲 All content fits naturally within 390px viewport (iPhone 13)
- 🍕 Improved scaling of visual elements on mobile

### Motion Sensitivity
- 🎭 Added `@media (prefers-reduced-motion: reduce)` support
- 🚫 Disables animations/transitions (0.001ms) for motion-sensitive users

### Print Improvements
- 🖨️ Enhanced print styles with `!important` flags for white background and black text

### Bug Fixes
- ✅ Carousel arrows now work at any viewport height and scale correctly

## Technical Details

- Carousel arrows use `position: absolute` with `top: 50%` and `transform: translateY(-50%)` for proper vertical centering
- Focus outline uses `outline` property with `outline-offset` for better visibility
- Mobile grid uses single column layout with reduced gap for better space utilization
