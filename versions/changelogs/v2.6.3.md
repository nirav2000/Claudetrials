## 📝 Commit Message

fix: Set up auth event listeners before initialization to catch redirect auth

Critical fix: Auth state change listeners must be registered BEFORE calling
authManager.initialize(), otherwise we miss the Firebase onAuthStateChanged
callback that fires during initialization after a redirect.

Also added comprehensive debug logging to track auth flow and UI updates.

This fixes the issue where user display name wasn't showing after Google login.
