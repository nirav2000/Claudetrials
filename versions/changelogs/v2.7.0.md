## 📝 Commit Message

```
feat: Add visible on-screen debug panel for iPad users

Since iPad users can't access the browser console, added a prominent
debug panel that displays all authentication events, status messages,
and errors directly on the page. The panel shows:

- Authentication initialization progress
- User login/logout events
- DOM element checks
- Configuration validation results
- All errors and warnings

This makes debugging authentication issues possible on iPad without
needing console access.
```
