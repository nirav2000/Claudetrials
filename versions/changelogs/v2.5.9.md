## 📝 Commit Message

```
fix: Add Firestore security rules for production mode authentication

CRITICAL FIX: Authentication was failing because Firestore is in production
mode, which denies all reads/writes by default.

Changes:
- Add firestore.rules with secure access rules for auth collections
- Add comprehensive FIRESTORE_SECURITY_RULES_GUIDE.md with step-by-step
  instructions to update security rules in Firebase Console
- Update FIREBASE_SETUP_GUIDE.md to highlight security rules as critical
  first step

Security rules allow:
- Users to read/write their own data only
- Email verification code creation (needed for signup)
- Login logging and session management
- All operations require authentication except code creation

The authentication system will work once these rules are published in
Firebase Console > Firestore Database > Rules tab.
```
