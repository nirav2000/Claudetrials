# Version 1.4.4 - Common Mistakes Mode

**Date:** 2026-01-22
**Type:** Minor Release

## Summary

Introduced Common Mistakes Mode - a targeted practice feature that generates problems focusing on specific error patterns students commonly make when comparing fractions.

## Features

### Common Mistakes Mode
- 🎯 New targeted practice mode for common fraction mistakes
- **5 Mistake Types:**
  1. **Higher Denominator Trap**: Same numerator, higher denominator (e.g., 2/3 vs 2/30)
  2. **Both Numbers Higher**: Both numerator and denominator higher (e.g., 1/2 vs 4/10)
  3. **Unit Fraction Confusion**: More slices = smaller pieces (e.g., 1/2 vs 1/8)
  4. **Near-Whole Comparison**: Both close to 1 (e.g., 5/6 vs 9/10)
  5. **Equivalent Fractions**: Same value, different representation (e.g., 1/4 vs 2/8)

### Customization
- Selectable mistake types for targeted practice
- Combined multiple mistake types
- Statistics tracking for each mistake type
- Explanations specific to each mistake pattern

## Educational Impact

- Addresses common misconceptions directly
- Provides focused practice on problem areas
- Helps students identify their weak points
- Improves understanding through targeted learning

## Technical Details

- Implemented mistake-specific problem generation algorithms
- Added mistake type selection UI
- Created targeted explanation system
