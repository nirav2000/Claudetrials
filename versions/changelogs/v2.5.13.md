# Version 2.5.13 - Use result.additionalUserInfo instead of firebase.auth.getAdditionalUserInfo

**Release Date:** 2026-01-30
**Type:** Patch Release
**Previous Version:** 2.5.12

## 🎯 Overview

Use result.additionalUserInfo instead of firebase.auth.getAdditionalUserInfo

## 🐛 Bug Fixes

- Use result.additionalUserInfo instead of firebase.auth.getAdditionalUserInfo

## 🔧 Improvements

- signInWithGoogle()
- signInWithFacebook()
- signInWithApple()

## 📝 Commit Message

```
fix: Use result.additionalUserInfo instead of firebase.auth.getAdditionalUserInfo

In Firebase v9+ (including compat mode), the UserCredential object returned
from signInWithPopup() contains additionalUserInfo as a direct property, not
as a method call. The firebase.auth.getAdditionalUserInfo() function doesn't
exist in the v9 compat API.

Changed from: firebase.auth.getAdditionalUserInfo(result)
Changed to: result.additionalUserInfo

This fix applies to all three social auth methods:
- signInWithGoogle()
- signInWithFacebook()
- signInWithApple()
```
