## 📝 Commit Message

```
refactor: Replace hardcoded SVG circles with dynamic utility generation

Previously, fraction circles were hardcoded as SVG elements in the HTML,
which meant fixes had to be applied individually to each occurrence.
This created inconsistencies (e.g., the 1/3 cup circle had 5 paths
instead of 3 equal slices).

Now all fraction circles are dynamically generated using the centralized
createCircleChart utility from js/utils/circleChart.js. This means:
- Bug fixes apply everywhere automatically
- Consistent rendering across all sections
- Single source of truth for circle generation
- Pizza Time, Time Management, Cooking & Recipes, Money & Shopping,
  and Sports sections all use the same utility

Removed hardcoded SVGs from:
- Pizza Time section (pizza-you, pizza-friend containers)
- Time Management section (time-management-circles container)
- Cooking & Recipes section (cooking-circles container)
- Money & Shopping section (money-circles container)
- Sports section (sports-circles container)

The general utility correctly handles all fractions including 1/3,
which now properly displays 3 equal slices with 1 filled.
```
