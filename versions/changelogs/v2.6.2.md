# Version 2.6.2 - Switch authentication to popup mode and fix UI update after login

**Release Date:** 2026-01-30
**Type:** Patch Release
**Previous Version:** 2.6.1

## 🎯 Overview

Switch authentication to popup mode and fix UI update after login

## 🐛 Bug Fixes

- Switch authentication to popup mode and fix UI update after login

## 🔧 Improvements

- Changed authMode from 'redirect' to 'popup' to keep users on the same page
- Fixed auth-ui.js to pass full result object to callbacks instead of just user
- Authentication now happens in popup window within modal context
- UI properly updates after successful authentication
