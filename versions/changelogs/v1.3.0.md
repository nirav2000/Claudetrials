# Version 1.3.0 - PDF Optimization

**Date:** 2026-01-22
**Type:** Minor Release

## Summary

Optimized PDF export functionality with improved layout, formatting, and better handling of visual elements for high-quality printable worksheets.

### PDF Export Enhancements
- 📄 Improved PDF layout and formatting
- Better page breaks for multi-page worksheets
- Optimized visual element rendering in PDFs
- Configurable PDF export options

### Print Improvements
- Cleaner print output
- Better handling of colors in print mode
- Improved margins and spacing
- Page number formatting

- Enhanced html2pdf.js configuration
- Better CSS print media queries
- Optimized element sizing for print
- Improved PDF generation performance
