# Version 2.8.2 - Add comprehensive popup window management for iOS/iPad authentication

**Release Date:** 2026-02-01
**Type:** Patch Release
**Previous Version:** 2.8.1

## 🎯 Overview

Add comprehensive popup window management for iOS/iPad authentication

## 🐛 Bug Fixes

- Add comprehensive popup window management for iOS/iPad authentication

## 🔧 Improvements

- Add explicit popup window monitoring and automatic closure detection
- Implement 60-second timeout with fallback auth state checking
- Add user-facing notifications when popup doesn't auto-close
- Provide popup blocker detection and help dialog with instructions
- Apply fixes consistently across all social auth providers

## 📝 Commit Message

```
fix: Add comprehensive popup window management for iOS/iPad authentication

Fixes issues with stuck popup windows during Google/Facebook/Apple sign-in on iPad:
- Add explicit popup window monitoring and automatic closure detection
- Implement 60-second timeout with fallback auth state checking
- Add user-facing notifications when popup doesn't auto-close
- Provide popup blocker detection and help dialog with instructions
- Apply fixes consistently across all social auth providers

This resolves the issue where popup windows would get stuck on the Firebase
auth handler page after successful authentication, particularly on iOS Safari/iPad.
```
