# Version 2.13.0 - Improve UX with inline feedback and better defaults

**Release Date:** 2026-02-02
**Type:** Minor Release
**Previous Version:** 2.12.0

## 🎯 Overview

Improve UX with inline feedback and better defaults

## ✨ New Features

- Improve UX with inline feedback and better defaults

## 🔧 Improvements

- Hidden by default for cleaner interface
- Added bug icon button in header to toggle debug panel
- Prevents debug panel from cluttering the view
- Changed from keyboard to buttons for better usability
- Buttons provide clearer visual feedback
- More intuitive for new users
- Replaced modal hints with inline display
- Hints now appear directly under problems
- Better user experience without interrupting workflow
- Added attractive gradient styling for visual aids
- Original problem clearly displayed at top of mistake feedback
- Shows user's incorrect answer with strikethrough
- Displays correct answer prominently
- Mistake explanation follows problem display
- Visual hints appear below mistake feedback
- Clear visual hierarchy for better learning
- Updated visualAids.js to use inline display
- Modified showHint and toggleHint functions
- Enhanced generateFeedbackHTML to include problem display
- Added CSS for .visual-aids-inline styling
- Added CSS for .mistake-original-problem display
- Improved mobile responsive styles
- Changed config DEFAULT_INPUT_METHOD to 'buttons'
- index.html
- js/core/config.js
- js/features/visualAids.js
- js/features/checkAnswers.js
- js/features/mistakeDetection.js
- css/features/visual-aids.css
- css/features/mistake-feedback.css

1. Debug Panel:
   - Hidden by default for cleaner interface
