# Version 2.5.6 - Lazy-load auth modules to prevent blocking app startup

**Release Date:** 2026-01-30
**Type:** Patch Release
**Previous Version:** 2.5.5

## 🎯 Overview

Lazy-load auth modules to prevent blocking app startup

## 🐛 Bug Fixes

- Lazy-load auth modules to prevent blocking app startup

## 🔧 Improvements

- Convert authManager/authUI/firebaseConfig to lazy-loaded variables
- Add loadAuthModules() method to dynamically import auth library
- Add guards to all methods that use authManager
- Check if modules are loaded before using them
- Main app now loads and works even if auth library has errors

## 📝 Commit Message

```
fix: Lazy-load auth modules to prevent blocking app startup

The 'can't find variable: authManager' error was caused by top-level
imports failing. This change makes auth modules load dynamically only
when needed, preventing any auth errors from breaking the main app.

Changes:
- Convert authManager/authUI/firebaseConfig to lazy-loaded variables
- Add loadAuthModules() method to dynamically import auth library
- Add guards to all methods that use authManager
- Check if modules are loaded before using them
- Main app now loads and works even if auth library has errors

This ensures worksheet functionality is never blocked by authentication
issues.
```
