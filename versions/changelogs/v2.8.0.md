**Previous Version:** 2.7.0

## ✨ New Features

- Intercept console.log to show in visible debug panel for iPad

## 📝 Commit Message

```
feat: Intercept console.log to show in visible debug panel for iPad

Since iPad users can't access the browser console, added a console.log
interceptor that displays all console messages in the visible debug panel.
This ensures that ALL debugging messages (including those from auth
libraries) are visible on-screen.

Now when the user returns from Google sign-in, all redirect flow
console.log messages will appear in the debug panel.
```
