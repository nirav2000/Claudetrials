## 📝 Commit Message

```
fix: Resolve Firebase global scope access in ES6 modules

Fixed the "firebase.auth.getAdditionalUserInfo is not a function" error by explicitly accessing Firebase from the window object in ES6 modules. Firebase is loaded via script tags in HTML and exists on the global window object, which needs explicit access in module scope.

Changes:
- Added `const firebase = window.firebase` to social-auth.js
- Added `const firebase = window.firebase` to auth-manager.js
- Updated Firebase availability check to use `window.firebase`

This ensures all Firebase API calls (GoogleAuthProvider, getAdditionalUserInfo, FieldValue, etc.) work correctly in the module context.
```
