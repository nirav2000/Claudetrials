# Version 2.6.0 - Add redirect-based authentication to avoid popup/new tab issues

**Release Date:** 2026-01-30
**Type:** Minor Release
**Previous Version:** 2.5.14

## 🎯 Overview

Add redirect-based authentication to avoid popup/new tab issues

## ✨ New Features

- Add redirect-based authentication to avoid popup/new tab issues

## 🔧 Improvements

- Default is 'redirect' for better UX and no popup blockers
- Configurable in auth-library/config/firebase-config.js
- signInWithRedirect() for redirect mode (same tab)
- signInWithPopup() for popup mode (legacy support)
- Google, Facebook, and Apple authentication
- Handles redirect result on page load
- Saves user data to Firestore
- Logs successful authentication
- Exported in index.js
- Automatically checks for redirect results on init
- Fires 'redirectAuthComplete' event on success
- Fires 'redirectAuthError' event on failure
- Listens for redirect auth events
- Shows appropriate notifications
- Handles both redirect and popup flows
- No more popup blockers or new tabs opening
- Cleaner user experience (stays in same tab)
- Works on all browsers and mobile devices
- Backward compatible with popup mode if needed
- 'redirect' - Recommended, redirects in same tab
- 'popup' - Opens popup window (may open as tab)

## 📝 Commit Message

```
feat: Add redirect-based authentication to avoid popup/new tab issues

Implemented redirect-based authentication as the default method to prevent
popups from being blocked or opened as new tabs, providing a smoother
authentication experience.

Changes:
1. Added authConfig.authMode setting ('redirect' or 'popup')
   - Default is 'redirect' for better UX and no popup blockers
   - Configurable in auth-library/config/firebase-config.js

2. Updated all social auth methods to support both modes:
   - signInWithRedirect() for redirect mode (same tab)
   - signInWithPopup() for popup mode (legacy support)
   - Google, Facebook, and Apple authentication

3. Added handleAuthRedirect() function:
   - Handles redirect result on page load
   - Saves user data to Firestore
   - Logs successful authentication
   - Exported in index.js

4. Updated AuthManager initialization:
   - Automatically checks for redirect results on init
   - Fires 'redirectAuthComplete' event on success
   - Fires 'redirectAuthError' event on failure

5. Enhanced auth-integration.js:
   - Listens for redirect auth events
   - Shows appropriate notifications
   - Handles both redirect and popup flows

Benefits:
- No more popup blockers or new tabs opening
- Cleaner user experience (stays in same tab)
- Works on all browsers and mobile devices
- Backward compatible with popup mode if needed

Configuration:
Set authMode in auth-library/config/firebase-config.js:
- 'redirect' - Recommended, redirects in same tab
- 'popup' - Opens popup window (may open as tab)
```
