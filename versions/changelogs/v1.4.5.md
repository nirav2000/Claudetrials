# Version 1.4.5 - Conditional Visual Aids

**Date:** 2026-01-22
**Type:** Minor Release

## Summary

Added conditional visual aids system that intelligently provides hints and visual representations when students need help, with configurable display options.

## Features

### Visual Aids System
- 👁️ Intelligent hint system with visual pizza diagrams
- Clickable problem numbers to reveal hints
- Pizza/circle diagrams for fraction visualization
- Decimal equivalents for comparison

### Configurability
- Hint timeout options (Off, 30s, 45s, 60s, 90s)
- Automatic hint reveal after timeout
- Manual hint toggling
- Print option for including/excluding visual aids

### Visual Representations
- Color-coded pizza diagrams
- Clear fraction-to-visual mapping
- Side-by-side comparison visualizations
- Explanatory text with visuals

## Educational Value

- Provides scaffolding for struggling students
- Encourages independent thinking first
- Visual learning support
- Better understanding through multiple representations

## Technical Details

- Implemented SVG-based pizza diagram generation
- Created timer system for hint timeouts
- Added visual aid rendering system
- Enhanced problem display with conditional content
